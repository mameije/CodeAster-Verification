# Shells

This family contains verification benchmarks for shell stability, currently for complete circular cylindrical shells using the native `COQUE_3D` formulation and `QUAD9` elements.

- [C01 — Uniform radial pressure](C01_Radial_Pressure/README.md): LA/LBA; benchmark comparison recorded; formal verification pending.
- [C02 — Uniform axial compression](C02_Axial_Compression/README.md): LA/LBA; five-mesh numerical comparison available; formal verification pending.

Refer to the central [verification register](../VERIFICATION_CASES.md) for the exact evidence and status of each case.
